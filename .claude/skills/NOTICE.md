# Third-party skills

The skills in this folder were copied unmodified from the
**Education Agent Skills Library** by Gareth Manning
(https://github.com/GarethManning/education-agent-skills, v3.1.0),
licensed under Creative Commons Attribution-ShareAlike 4.0 International
(https://creativecommons.org/licenses/by-sa/4.0/).

They guide how lesson content for `learn.html` ("הכיתה") is designed:

| Skill | Used for |
|---|---|
| explicit-instruction-sequence-builder | The station order: I do → We do → You do |
| worked-example-fading-designer | "דוגמה פתורה" → "פותרים יחד" (steps hidden, revealed one by one) |
| checking-for-understanding-protocol-designer | Checks between stations |
| retrieval-practice-generator | Recall cards for key terms |
| hinge-question-designer | Writing the readiness-check questions and distractors |
| adaptive-hint-sequence-designer | Writing graded hints in `data/*.js` |
| retrieve-first-gate | The "learn before practice" gate |
| confidence-calibration-check | Before/after confidence rating |
